# PEMAT review

Source: AHRQ PEMAT (Shoemaker, Wolf and Brach 2014). Japanese version validated by Furukawa et al. (2022).

Rate each item **Agree (1)**, **Disagree (0)** or **N/A** (only where shown). Agree only if the item holds nearly all the time (about 80-100%). Rate items independently and use only what is in the material.

## Understandability (print: items 1-12 and 15-19)

| # | Item | N/A allowed |
| --- | --- | --- |
| 1 | The material makes its purpose completely evident. | no |
| 2 | The material does not include information or content that distracts from its purpose. | no |
| 3 | The material uses common, everyday language. | no |
| 4 | Medical terms are used only to familiarize audience with the terms. When used, medical terms are defined. | no |
| 5 | The material uses the active voice. | no |
| 6 | Numbers appearing in the material are clear and easy to understand. | if no numbers |
| 7 | The material does not expect the user to perform calculations. | no |
| 8 | The material breaks or "chunks" information into short sections. | if very short |
| 9 | The material's sections have informative headers. | if very short |
| 10 | The material presents information in a logical sequence. | no |
| 11 | The material provides a summary. | if very short |
| 12 | The material uses visual cues (e.g. arrows, boxes, bullets, bold, larger font, highlighting) to draw attention to key points. | no (print) |
| 15 | The material uses visual aids whenever they could make content more easily understood. | no |
| 16 | The material's visual aids reinforce rather than distract from the content. | if no visual aids |
| 17 | The material's visual aids have clear titles or captions. | if no visual aids |
| 18 | The material uses illustrations and photographs that are clear and uncluttered. | if no visual aids |
| 19 | The material uses simple tables with short and clear row and column headings. | if no tables |

Items 13 and 14 are for audio/video only (text on screen easy to read; words heard clearly). Use them, and leave out 19, for narration or video (PEMAT-A/V).

## Actionability (items 20-26)

| # | Item | N/A allowed |
| --- | --- | --- |
| 20 | The material clearly identifies at least one action the user can take. | no |
| 21 | The material addresses the user directly when describing actions. | no |
| 22 | The material breaks down any action into manageable, explicit steps. | no |
| 23 | The material provides a tangible tool (e.g. checklists) whenever it could help the user take action. | no |
| 24 | The material provides simple instructions or examples of how to perform calculations. | if no calculations |
| 25 | The material explains how to use the charts, graphs, tables, or diagrams to take actions. | if none |
| 26 | The material uses visual aids whenever they could make it easier to act on the instructions. | no |

## Score

Understandability % = agree / (items not N/A) x 100. Actionability the same for items 20-26. 70% or more is the cut-off most studies use.

## Output

A table with item, rating, one-line reason quoting the material, and the fix for each Disagree. Then the two percentages. If two people (or two runs) rate, report both and where they differ.

Note: information-only material (no action asked of the reader) will score low on actionability. Say so rather than adding artificial actions; a natural action is "questions to ask your dentist or doctor".
