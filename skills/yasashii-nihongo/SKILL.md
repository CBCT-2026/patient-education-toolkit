# やさしい日本語での書きかえ

出典：出入国在留管理庁・文化庁「在留支援のためのやさしい日本語ガイドライン」（2020）、文部科学省「学年別漢字配当表」（2020）。

## ルール

- **1文1情報**。1文はだいたい50字以下（`ja-sentence-length` の目安）。
- **文の最後まで言い切る**。あいまいな表現をさけ、数字ははっきり書く（「100人に7人ぐらい」）。
- **二重否定をさけ**（「ないこともない」→ 肯定の形）、受け身・使役もできるだけさける。
- **敬語は「です・ます」まで**。「いただく」「ございます」「おります」は使わない。
- **専門用語は言いかえる**。患者が知っておくべき用語は残し、説明を付ける（「下あごの神経（かしそう神経）」）。
- **漢字の熟語をへらす**。プロジェクトの設定に合わせ、小学校で習う漢字（教育漢字1,026字）以外はひらがなにするか、言いかえる（`ja-kanji` がチェック）。漢字の割合はだいたい35%以下。
- **カタカナ語・和製英語・オノマトペ（擬音語・擬態語）はさける**。必要なときは説明を付ける。症状の説明で「ピリピリ」などを使う場合は、ほかの言葉もいっしょに書く。
- **3つ以上ならべるときは箇条書き**にする。
- **絵・写真・記号**で内容を助ける。
- **主語**：英語版が "you" で書かれていても、日本語では主語を省くのが自然です。「あなた」を多用しない（プロジェクト設定 `ja_address_reader`）。
- **子どもあつかいしない**。ていねいで、短く、はっきり。

## 進め方

1. 事実、数字、引用マーク、リンクはすべて残す。事実を足さない。
2. 英語版がある場合は、内容（数字、節、図）が同じかを `cross-format-consistency` で確認する。
3. 書きかえたら `pitk check` を実行し、エラーを直す。
4. 変更前と変更後を並べてユーザーに見せる。
